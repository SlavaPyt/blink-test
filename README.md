# blink-test

Первый шаг моего проекта, датчика скорости штанги для силовых тренировок (velocity-based training) на ESP32-C3.

Проект в разработке.

## Что уже работает

Прошивка для платы ESP32-C3 SuperMini: мигает встроенным светодиодом (GPIO8) и пишет "горит" и "погас" в Serial по USB.

## Что дальше

1. Подключить акселерометр и гироскоп MPU6050 по I2C и написать свой драйвер без библиотек
2. Сбор данных с ровной частотой и запись подходов в зале
3. Алгоритм скорости штанги и приложение для телефона

## Стек

C++, Arduino, PlatformIO, ESP32-C3 (RISC-V)

## Как запустить

1. Открыть папку в VS Code с расширением PlatformIO.
2. Подключить плату по USB-C и нажать Upload.
3. Открыть Serial Monitor (115200 бод).
